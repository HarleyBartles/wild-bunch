# Design runbook

This overlay supplies Wild Bunch-specific inputs after `using-superpowers-plus`
routes design work to `brainstorming`.

## Local design constraints

- Read [coding discipline](../docs/coding-discipline.md) for scope and the
  mandatory architecture posture.
- Read [architecture guardrails](../docs/architecture-guardrails.md) when the
  design touches GameSession, domain logic, persistence, commands, queries, or
  projections.
- Read [frontend standards](../docs/frontend-standards.md) for browser delivery
  or player-facing UI.
- Read [validation policy](../docs/validation-policy.md) so the contract names
  the required Wild Bunch evidence lanes.
- Read [mesh policy](../docs/mesh-policy.md) when the design changes agent-facing
  routes, doctrine, or generated indexes.

## Local artifact path

Active design specifications live in `.agents/specs/`. Completed specifications
leave the tracked tree under [completed-artifacts doctrine](../doctrine/completed-artifacts.md).

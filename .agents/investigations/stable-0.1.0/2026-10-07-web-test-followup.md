# Web test follow-up

**Status:** Proposed test dispositions for the interactive stable `0.1.0` investigation. This follows the [Web source investigation](2026-10-07-web-layer-investigation.md) and the earlier [full test-quality audit](2026-10-06-test-quality-investigation.md). No production code or tests were changed, and no suite, browser or service was run. This follow-up selectively rereads relevant setup/assertions/helpers against WB-01 through WB-24; it does not claim another exhaustive full read of every frontend test file.

**Scope:** The tracked frontend inventory remains 42 test files and four support/guidance files. The disposition table reconciles all 46, using the earlier full-read assessment plus this targeted follow-up. Four map handler/HTTP test files were reread in full because the user's one-map clarification crosses that boundary. Backend feature/lifecycle dispositions from the Application and Domain follow-ups remain applicable.

## One world map, including backend test ownership

`tests/WildBunch.Application.Tests/Handlers/GetStartingTownMapHandlerTests.cs` asserts selectability through a count of eight, complete trail coverage through NotEmpty and correct distances through positivity. The endpoint suite repeats these weak fragments. `GetWorldMapHandlerTests.cs` invokes the exact same starting-map handler; its missing-session negative remains useful. `tests/WildBunch.Integration.Tests/WorldMapEndpointTests.cs:27-46` compares only town/trail counts under SameShape. Two wrong responses can satisfy that agreement.

Consolidate at the canonical world-map query/projection owner. Use an explicitly arranged world with distinct coordinates, services, edge IDs/endpoints and distances; compare complete public output with independent expected values. Preserve missing-session handling, real HTTP serialization and meaningful hidden-truth exclusion with a successful populated response. If both URLs remain supported, compare their actual payload facts in a thin compatibility scenario. If an alias is deliberately removed, retire its compatibility tests with the contract change; do not maintain duplicate handler suites or require two map resources because old names exist.

The frontend world-map capability protects display and intent. Setup and travel tests protect different selection rules. Shared terrain/map facts must not fork by interaction. Do not freeze a particular query-key spelling, path to PhaserMapHost, scene class name or exact number of fetches permitted by normal Query refetch policy.

## Consolidation and placement

Group successful setup walks into one full routed scenario plus focused validation/rejection/resume boundaries. Group settings/open/confirm/cancel/archive effects now repeated across GameSettingsOverlay, StartOverConfirmation, StartOverRegression, StorePlaceFeedback and AppShell at the lifecycle owner; retain distinct player reachability and real route transition coverage. Consolidate repeated scene mount/selection/readonly fragments, per-option callbacks and developer invocation/display fragments while preserving independently meaningful negatives. Small pure-function cases and deterministic asset/planning properties are not automatically TDD sprawl.

TravelRoutesPanel is unmounted scaffolding. Its tests are not a reason to expand that obsolete path's failure matrix. Decide retained interaction first, transfer useful preview/dispatch obligations to the routed travel slice and retire tests with the discarded shell. Apply the same rule to other unmounted components, legacy helpers and unrelated-criminal consumers.

The tests README forbids colocation despite three shipped colocated renderer suites. That policy must be reconciled with the agreed vertical-slice ownership. Capability tests can live with their capability; genuinely shared fixtures/harness code have a deliberate owner. Moving tests must not create a new folder-count/path assertion. If import direction/public entry boundaries are adopted, enforce the declared dependencies with maintained tooling and meaningful validator negatives, not a brittle inventory of source filenames.

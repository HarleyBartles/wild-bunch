# Dev overlay proof contract

A completed dev-overlay change reports these independently checkable fields:

- worktree, branch, API URL, and frontend URL;
- scenario and deterministic setup used;
- dev command and immutable dev-event receipt;
- normal gameplay command that consumed the prepared state;
- resulting normal gameplay event/outcome;
- compact, expanded, and default-panel screenshots when UI changed;
- candidate controls expressed with resolved names and domain meaning, not raw
  identifier entry, when applicable;
- backend and frontend test results; and
- console or network errors observed during browser proof.

Generated screenshots and evidence remain in the branch-scoped scratch
workspace and are not committed.

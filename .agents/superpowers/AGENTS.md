# Superpowers Artifact Placement

This document provides durable guidance for agents and subagents executing superpowers workflows in this repo.

## Artifact Placement

When executing superpowers workflows, direct all tracked artifacts to the appropriate subdirectory under `.agents/superpowers/`:

### Plans
- **Location**: `.agents/superpowers/plans/`
- **Content**: Implementation plans with structured breakdowns
- **Status**: Tracked in git, committed with the plan

### Session Artifacts
- **Location**: `.agents/superpowers/sdd/<plan-name>/`
- **Content**: Session-specific artifacts organized by plan
  - Commit messages
  - PR updates
  - Progress tracking
  - Review diffs
  - Test output
- **Organization**: Create a subfolder named after the plan (e.g., `2026-07-03-generate-trails-from-settled-town-geometry/`) and place all session artifacts for that plan inside it
- **Status**: Tracked in git, committed with the session work

### Output (Binary/Evidence)
- **Location**: `.agents/superpowers/output/`
- **Content**: Screenshots, browser evidence, and other binary artifacts
- **Status**: Git-ignored (see `.gitignore` in that directory)
- **Note**: PR/return notes may cite local evidence filenames/paths or attach screenshots through the review system, but must not add them as repo files

## Prohibited Locations

- **Do not** create loose files at repo root (no `COMMIT_MSG.txt`, `PR_BODY.md`, scratch notes, etc.)
- **Do not** create `.superpowers/` at repo root (use `.agents/superpowers/` instead)
- **Do not** place agent-generated artifacts under `docs/`, product source folders, or other non-superpowers directories

## Index Mesh

The `INDEX.md` file in this directory is generated by `scripts/generate_index_mesh.py`. Do not hand-edit it for durable guidance — update this `AGENTS.md` file instead, then regenerate the index mesh.

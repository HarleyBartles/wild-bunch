## Summary

BUNCH-75: Phaser-backed world map POC for starting-town selection and trail awareness.

- **Backend read model:** `SeedWorldMapLayout` adds deterministic town coordinates and trail edges next to the existing `SeedWorldCatalog`. `GetStartingTownMapHandler` reuses `StartingTownCatalog.GetStartingTownCandidates()` for eligibility — no second eligibility algorithm. Exposed via `GET /api/games/starting-town-map` (setup-scoped, no session required).
- **Phaser host:** `PhaserMapHost.tsx` mounts a Phaser scene that renders towns and trail edges from backend-sourced map data, emits `townSelected` intent to React, and unmounts cleanly. Phaser has no API client, no fetch access, no mutation access. `selectedTownId` is `public readonly` on the scene.
- **React-owned confirmation:** `StartingTownStep.tsx` wires the Phaser host but keeps selection state, detail panel, and confirm action in React. Game creation still flows through `POST /api/games` via React-owned confirmation — Phaser never calls it. Falsifiable tests prove this boundary.

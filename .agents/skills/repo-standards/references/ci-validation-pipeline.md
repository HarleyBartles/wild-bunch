# CI validation pipeline

Every repo that uses `repo-standards` should have a `tools/run.py` task runner
that composes the same checks CI runs for that repo. The canonical `ci` task
applies mechanical surfaces and then verifies them in a fail-fast order:
`lint`, `repo-standards`, `validate`, and `archive-links`. Pass `--check` to
validate without writing. The `.git/hooks/pre-commit` hook runs `ci --apply`,
and CI runs the same targets as separate workflow steps.

## Preflight: `tools/run.py ci`

The `ci` task is repo-owned. By default `tools/run.py ci --apply` applies changes
(for example, formatting and regenerating the agent mesh), then checks each step
before moving to the next. Pass `--check` to validate without writing. The
`repo-standards` pre-commit template calls `tools/run.py ci --apply` directly.

## Pre-commit hook: `.git/hooks/pre-commit`

The hook is generated by `repo-standards` and executes `tools/run.py ci --apply`
for every commit. If any step fails, the commit is blocked. This ensures each
pushed commit has passed the local checks. Do not bypass the hook with
`--no-verify`.

## CI workflow

CI composes the same checks as separate workflow steps. Each step has its own
label so failures are easy to attribute. CI does not call the preflight script;
it runs the same commands directly.

## What to do when a check fails

Every check target must print the repair command to stderr before exiting. For
example:

- lint -> `python -m ruff check --fix <files> && python -m ruff format <files>`
- repo shape -> `python .agents/skills/repo-standards/scripts/repo_standards.py --apply --yes`
- agent mesh -> `python .agents/skills/generating-agent-mesh/scripts/generate_index_mesh.py`
- marketplace drift -> `python tools/validate_marketplace.py`

Run the repair command, then re-run `tools/run.py ci --check`.

## Template menu

The `repo-standards` pre-commit template calls `tools/run.py ci --apply`. A repo
can run the same tasks manually or wire them into CI:

- `py -3 tools/run.py ci --check`
- `py -3 .agents/skills/repo-standards/scripts/repo_standards.py --check`
- `py -3 .agents/skills/repo-standards/scripts/scaffold-all.sh --check`
- `py -3 .agents/skills/generating-agent-mesh/scripts/validate_agent_mesh.py --check`
- `py -3 .agents/skills/refreshing-installed-skills/scripts/refresh_installed_skills.py --check`
- repo-specific lint command
- repo-specific final CI command

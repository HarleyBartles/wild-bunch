# Transactions and concurrency

Use this reference when handling transactions, isolation levels, locking, or
deadlocks. Choose the lowest isolation level that guarantees correct results for
the workload; add explicit locking only when optimistic concurrency fails.

The authority is the BCcampus textbook chapters on transactions, concurrency
control, locking, and deadlock. Adapt the ACID and isolation-level descriptions
into operational rules. Explain how to detect and break deadlocks without
losing correctness.

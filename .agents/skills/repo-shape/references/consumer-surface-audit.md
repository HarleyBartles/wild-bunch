## Ownership boundary

Marketplace packaging decides which skills a plugin contains and whether projections from different plugins are consistent. Consumer conformance checks only that required plugin subscriptions exist and that workflow skill links resolve in the consumer-visible namespace.

Consumer-generated indexes are not projections of this marketplace's indexes. The portable standard requires a declared generator and current output, while each consumer owns the generator and the resulting index contents.

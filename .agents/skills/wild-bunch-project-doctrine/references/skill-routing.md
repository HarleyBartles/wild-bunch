# Skill Routing

Invoke only installed skills and load the smallest set that owns the task.

## Repository workflow

- `using-superpowers` — select the controlling workflow.
- `work-mode-router` — classify a new or resumed repository task.
- `repo-worker-base` — apply worktree, custody, validation, and publication boundaries.
- `inspecting-the-environment` — verify shell, worktree, branch, tools, authority, and protected surfaces.
- `using-git-worktrees` — create or verify isolated worktrees.

## Planning, implementation, and review

- `brainstorming` — clarify a design before creative implementation.
- `writing-plans` — produce a repository-backed implementation plan.
- `executing-plans` or `subagent-driven-development` — execute an approved plan.
- `test-driven-development` — implement behavior changes test-first.
- `systematic-debugging` — diagnose failures before changing code.
- `requesting-code-review` — review completed work.
- `verification-before-completion` and `finishing-a-development-branch` — verify and close out a branch.

## External evidence and safety

- `using-linear` and `linear-issue-shaping` — Linear issue and project work.
- `github-operations` — GitHub branch, PR, review, check, and merge proof.
- `connector-safety` and `risk-gates` — sensitive or consequential mutations.
- `unslop-plus` — task-specific quality profiles.

## Wild Bunch specialists

- `wild-bunch-project-doctrine` — repository posture and routing.
- `wild-bunch-domain-modeling` — `GameSession` ownership and gameplay invariants.
- `wild-bunch-dotnet-architecture` — .NET application and persistence boundaries.
- `wild-bunch-browser-game` — browser delivery and QA boundaries.

## Architecture discovery

Inspect live source first, then select from:

- `ddd` for aggregates, value objects, and domain events;
- `cqrs` for command/query separation;
- `event-sourcing` for event streams, replay, and snapshots;
- `event-driven-architecture` for events and projections;
- `clean-architecture` for dependency direction and layer boundaries;
- `dotnet` for C# and .NET implementation guidance;
- the three Wild Bunch specialists for repository-specific decisions.

Do not substitute retired or unavailable names for these installed skills.

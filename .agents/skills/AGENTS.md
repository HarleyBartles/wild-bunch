# Skills AGENTS.md

## Skill Updates

**DO NOT UPDATE SKILLS IN THIS REPO.**

Skills are only updated from the plugin source repo. Any changes to skills must be made in the plugin source repository, not in this repo's `.agents/skills/` directory.

The skills in this directory are vendored from the plugin source and should be treated as read-only. If you need to update a skill:
1. Make the change in the plugin source repository
2. The plugin will vendored the updated skill to this repo
3. Do not manually edit skill files in this repo

This ensures consistency across all repos using the same plugin and prevents divergence.

# BUNCH-103: Install Wild Bunch Repo-Local Plugins and Agent/Index/README Mesh — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **Re-ground history:** This plan was originally preflighted against a 3-pack default topology (`repo-worker-pack`, `superpowers-plus`, `wild-bunch-project-pack`) when `wild-bunch-project-pack` was over-broad. MARK-315 (merged at marketplace commit `86484b2`) normalized the project-pack topology so `wild-bunch-project-pack` is thin (5 bridge skills only). The plan was repaired in-place to target the full 7-pack default dependency stack and to retain genuinely uncovered skills (notably `crew`) as temporary project custody instead of deleting them. No `agent-browser` ghost references are carried.

**Goal:** Replace the copied `.agents/skills/` snapshot mesh in `HarleyBartles/wild-bunch` with a repo-local Codex plugin marketplace manifest that default-installs the full dependency stack — `repo-worker-pack`, `superpowers-plus`, `wild-bunch-project-pack`, `game-studio`, `dotnet-kit`, `architecture-pack`, and `frontend-pack` — and install the full agent/index/README mesh contract: root `AGENTS.md` as the repo-wide law entrypoint, scoped `AGENTS.md` nodes only where local law changes, a repo-resident agent-facing mesh-policy doc, generated `INDEX.md` navigation mesh driven by a repo-local generator with a CI check-mode validator, and README updates where human discoverability is needed.

**Architecture:** This is a metadata/docs/tooling slice. No Wild Bunch game, domain, persistence, or web source code changes. The plugin posture lives in a new `.agents/plugins/marketplace.json` that mirrors the canonical `agent-asset-marketplace` manifest shape but is scoped to seven default-installed packs and points at the canonical marketplace repo as the install source. The corrected topology (post MARK-315, merged at marketplace commit `86484b2`) keeps `wild-bunch-project-pack` thin — it contains only the five Wild Bunch native/bridge skills (`wild-bunch-project-doctrine`, `wild-bunch-domain-modeling`, `wild-bunch-dotnet-architecture`, `wild-bunch-browser-game`, `wild-bunch-worker-verification`). The remaining local skill coverage comes from separately installed dependency plugins: `game-studio`, `dotnet-kit`, `architecture-pack`, `frontend-pack`, plus `repo-worker-pack` and `superpowers-plus` for the worker/workflow baseline. The copied `.agents/skills/` tree is reduced once coverage is proven: 47 of 48 folders are covered by marketplace plugins (29 by the default stack, 18 by AVAILABLE packs) and removed; the single uncovered local skill (`crew`) is retained as temporary Wild Bunch project custody with a named reason and proposed follow-up. The agent law mesh stays authored (`AGENTS.md` files) and is repaired where stale references to `.agents/skills/` remain. The `INDEX.md` mesh becomes generated by a new repo-local Python generator (`scripts/generate_index_mesh.py`) modeled on the marketplace repo's `tools/generate_index_mesh.py`, with a `--check` mode wired into CI. A new `.agents/docs/mesh-policy.md` documents the three-surface contract. A new root `README.md` gives humans a discoverable entrypoint without carrying operative agent law.

**Tech Stack:** Markdown (`AGENTS.md`, `INDEX.md`, `README.md`, `.agents/docs/*.md`), JSON (`.agents/plugins/marketplace.json`), Python 3 (`scripts/generate_index_mesh.py`), GitHub Actions YAML (`.github/workflows/ci.yml`).

- Default-installed plugins are exactly: `repo-worker-pack`, `superpowers-plus`, `wild-bunch-project-pack`, `game-studio`, `dotnet-kit`, `architecture-pack`, `frontend-pack`. Do not default-install `house-skills` or any other pack.

- The repo-local marketplace manifest points at the canonical marketplace repo as the install source; it does not re-declare plugin internals (skills, manifests, provenance).
- Worker environment uses PowerShell; do not use `&&` for command chaining.
- Validation: `dotnet build` and `dotnet test` are not affected by this metadata-only slice but must still pass (regression guard). The new index-mesh check and JSON validation are the primary new validation.
- Source of truth: current repo state. The marketplace repo `HarleyBartles/agent-asset-marketplace` is the canonical plugin source; this plan's coverage claims are grounded against its current `HEAD` plugin skill lists.

**Decision A — INDEX.md description loss:** The marketplace generator renders directory/file names as links without prose descriptions. The current hand-authored Wild Bunch `INDEX.md` files carry short descriptions. Adopting the generator drops those descriptions. This is the accepted tradeoff for a generated, checkable, drift-free mesh: descriptions belong in `AGENTS.md` law or README human docs, not in generated navigation. If a description is operative law, it must move to the nearest `AGENTS.md` before regeneration. The plan includes a pre-regeneration audit step (Task 5) to catch any description that is actually law and relocate it.

# Mesh Policy

This is the agent-facing contract for the three documentation/navigation surfaces in this repo. It is the detailed companion to the binding summary in [../../AGENTS.md](../../AGENTS.md). When the two disagree, root `AGENTS.md` wins and this doc must be repaired in the same PR.

## 1. `AGENTS.md` mesh

`AGENTS.md` files are authored scoped law. They answer: what is lawful here, what differs from upstream law, and what upstream law still applies.

- The nearest scoped `AGENTS.md` applies to the subtree an agent is working in, with root law inherited unless a nearer node adds a local delta.
- Add or update scoped `AGENTS.md` nodes only at meaningful law-boundary nodes — not every folder needs one.
- No `AGENTS.md` should be siloed; scoped nodes must be understandable from root agent law and the upstream nodes between here and root.
- `AGENTS.md` should explain rules, boundaries, and source/projection distinctions, not directory navigation.
- Do not add `AGENTS.md` files inside individual skill roots or generated plugin skill roots; skill roots use `SKILL.md` as the entrypoint.

## 2. `INDEX.md` mesh

`INDEX.md` files are generated navigation and coverage surfaces. They answer: what is here, where can I go, and how do I get back to root?

- They are generated by `scripts/generate_index_mesh.py`. Do not hand-edit them.
- They must not carry operative law.
- They must not be inserted into skill roots, adapter overlay roots, or generated plugin skill roots.
- Stale `INDEX.md` is fixed by regenerating the whole mesh via the generator, never by hand-editing individual files or regenerating only a subtree.
- If whole-mesh regeneration does not produce a valid mesh, fix the generator, exclusion policy, or source inputs.

## 3. `.agents/` tree

`.agents/` is the tracked repo-resident home for agent-facing doctrine, local plugin posture, agent work surfaces, and output/evidence conventions.

- It is not disposable cache.
- It is not the home for ordinary product/source work unless that source is agent-facing infrastructure.
- Repo-local plugin posture lives in `.agents/plugins/marketplace.json`.
- Agent-facing doctrine docs live under `.agents/docs/`.
- Unslop profiles live under `.agents/unslop/` (repo-wide) and `{project}/.agents/unslop/` (project-local).
- Superpowers plan records and git-ignored evidence output live under `.agents/superpowers/`.

## 4. README files

README files are human-facing. They are not a mesh.

- Do not put operative agent law only in README.
- If a README is stale or contains agent law, repair it or move the law into the agents mesh.
- The root `README.md` is a human discoverability entrypoint that points at `AGENTS.md` for agent law and `INDEX.md` for navigation.

## 5. Mesh self-healing

- If a worker finds stale or misleading authored mesh law (`AGENTS.md`, `README.md`, or other agent-facing doctrine docs), repair it in scope or return AMBER with the exact deferred repair.
- If a worker finds stale generated `INDEX.md` navigation, repair it by regenerating the whole index mesh through `scripts/generate_index_mesh.py`.
- Do not hand-edit individual generated `INDEX.md` files or regenerate only a subtree to satisfy CI.

## 6. Plugin posture

- Default-installed plugins are declared in `.agents/plugins/marketplace.json`.
- Do not vendor copied `.agents/skills/` folders for skills that have a marketplace plugin home. Genuinely uncovered skills may be retained as temporary project custody with a named reason and proposed follow-up.
- `house-skills` is not default-installed in this repo.
- Plugin skills are sourced from `HarleyBartles/agent-asset-marketplace`; this repo does not re-vendor plugin internals.

## 7. Temporary project-custody skills

`.agents/skills/` may retain genuinely uncovered skills that have no current marketplace plugin home. These are temporary Wild Bunch project custody, not vendored plugin copies.

- Each retained skill must have a named reason: why no current plugin covers it, whether it should later move into a marketplace plugin, and a proposed follow-up MARK issue category.

- Do not add plugin-covered skills here. If a skill is covered by a default-installed or AVAILABLE marketplace pack, it belongs in the plugin, not in local custody.

This is a repo-local adaptation of `HarleyBartles/agent-asset-marketplace/tools/generate_index_mesh.py`. Differences from the upstream script: the exclusion set is the Wild Bunch set (`bin`, `obj`, `node_modules`, `.git`, `.worktrees`, `.local`, `bin`, `obj`); there is no `sources/third_party` or `generated/skill-zips` root to special-case; the rendered shape is identical (`# INDEX.md`, generated-by note, `## Directories`, `## Files`).

```python
#!/usr/bin/env python3
"""Generate or validate the repo-wide INDEX.md mesh for wild-bunch."""

from __future__ import annotations

import argparse
import os
import re
from dataclasses import dataclass
from pathlib import Path


ROOT = Path(__file__).resolve().parents[1]
EXCLUDED_DIR_NAMES = {".git", ".worktrees", "__pycache__", "bin", "obj", "node_modules", ".local"}
EXCLUDED_ROOT_NAMES = {".git", ".worktrees", "__pycache__", "bin", "obj", "node_modules", ".local"}
EXCLUDED_FILE_NAMES = {".git"}


@dataclass(frozen=True)
class IndexTarget:
    path: Path
    lines: list[str]


LINK_PATTERN = re.compile(r"\[([^\]]+)\]\(([^)]+)\)")


def is_skill_root(path: Path) -> bool:
    return (path / "SKILL.md").exists() or (path / "overlay.yaml").exists()


def is_under(path: Path, ancestor: Path) -> bool:
    return path == ancestor or ancestor in path.parents


def should_descend(child: Path) -> bool:
    return child.name not in EXCLUDED_DIR_NAMES and not is_skill_root(child)


def should_index(path: Path) -> bool:
    if path == ROOT:
        return True
    relative = path.relative_to(ROOT)
    if any(part in EXCLUDED_ROOT_NAMES for part in relative.parts):
        return False
    return not is_skill_root(path)


def rel_link(target: Path, label: str | None = None) -> str:
    rel = target.relative_to(ROOT).as_posix()
    return f"[{label or target.name}]({rel})"


def dir_link(current: Path, child: Path) -> str | None:
    skill_md = child / "SKILL.md"
    if skill_md.exists():
        return f"[{child.name}]({skill_md.relative_to(ROOT).as_posix()})"
    if should_index(child):
        return f"[{child.name}]({child.relative_to(ROOT).as_posix()}/INDEX.md)"
    return f"[{child.name}]({child.relative_to(ROOT).as_posix()}/)"


def render_index(path: Path) -> str:
    dirs = []
    files = []
    for entry in sorted(path.iterdir(), key=lambda p: (not p.is_dir(), p.name.casefold(), p.name)):
        if entry.name == "INDEX.md":
            continue
        if entry.is_dir():
            if entry.name in EXCLUDED_DIR_NAMES:
                continue
            if is_skill_root(path):
                continue
            dirs.append(entry)
        else:
            if entry.name in EXCLUDED_FILE_NAMES:
                continue
            files.append(entry)

    lines: list[str] = ["# INDEX.md", ""]
    lines.append("This index is generated by `scripts/generate_index_mesh.py`.")
    lines.append("")

    if dirs:
        lines.append("## Directories")
        for child in dirs:
            link = dir_link(path, child)
            if link is not None:
                lines.append(f"- {link}")
        lines.append("")

    if files:
        lines.append("## Files")
        for child in files:
            lines.append(f"- {rel_link(child)}")
        lines.append("")

    if not dirs and not files:
        lines.append("No child entries.")
        lines.append("")

    return "\n".join(lines).rstrip() + "\n"


def normalize_text(text: str) -> str:
    return text.replace("\r\n", "\n").replace("\r", "\n")


def resolve_link_target(current: Path, target: str) -> Path | None:
    if target.startswith(("http://", "https://", "mailto:")):
        return None
    clean_target = target.split("#", 1)[0]
    if not clean_target:
        return None
    candidates = [
        (current.parent / clean_target).resolve(),
        (ROOT / clean_target).resolve(),
    ]
    for resolved in candidates:
        if not is_under(resolved, ROOT):
            continue
        if target.endswith("/"):
            if resolved.is_dir():
                return resolved
            continue
        if resolved.exists():
            return resolved
    return None


def validate_rendered_links(path: Path, rendered: str) -> list[str]:
    failures: list[str] = []
    for label, raw_target in LINK_PATTERN.findall(rendered):
        resolved = resolve_link_target(path, raw_target)
        if resolved is None:
            continue
        if raw_target.endswith("/"):
            if not resolved.is_dir():
                failures.append(f"broken-link: {path.relative_to(ROOT)} -> {raw_target}")
            continue
        if not resolved.exists():
            failures.append(f"broken-link: {path.relative_to(ROOT)} -> {raw_target}")
    return failures


def walk_index_targets() -> list[IndexTarget]:
    targets: list[IndexTarget] = []
    for dirpath, dirnames, _filenames in os.walk(ROOT):
        current = Path(dirpath)
        dirnames[:] = sorted(
            (name for name in dirnames if should_descend(current / name)),
            key=lambda name: (name.casefold(), name),
        )
        if should_index(current):
            targets.append(IndexTarget(path=current / "INDEX.md", lines=render_index(current).splitlines()))
    return targets


def main() -> int:
    parser = argparse.ArgumentParser(description="Generate or validate the repo-wide INDEX.md mesh")
    parser.add_argument("--check", action="store_true", help="validate without writing")
    args = parser.parse_args()

    targets = walk_index_targets()
    expected_paths = {target.path for target in targets}
    actual_paths = {
        path
        for path in ROOT.rglob("*")
        if path.is_file() and path.name == "INDEX.md" and not any(part in EXCLUDED_ROOT_NAMES for part in path.relative_to(ROOT).parts)
    }
    unexpected = sorted(path for path in actual_paths if path not in expected_paths)
    missing = sorted(path for path in expected_paths if path not in actual_paths)

    if args.check:
        mismatches: list[str] = []
        for target in targets:
            if not target.path.exists():
                mismatches.append(f"missing: {target.path.relative_to(ROOT)}")
                continue
            current = normalize_text(target.path.read_text(encoding="utf-8"))
            rendered = "\n".join(target.lines).rstrip() + "\n"
            if current != rendered:
                mismatches.append(f"stale: {target.path.relative_to(ROOT)}")
            mismatches.extend(validate_rendered_links(target.path, rendered))
        if unexpected:
            mismatches.extend(f"unexpected: {path.relative_to(ROOT)}" for path in unexpected)
        if missing:
            mismatches.extend(f"missing: {path.relative_to(ROOT)}" for path in missing)
        if mismatches:
            raise ValueError("INDEX mesh is stale or inconsistent:\n" + "\n".join(mismatches))
        print(f"OK index mesh: {len(targets)} indexes current")
        return 0

    written = 0
    for target in targets:
        rendered = "\n".join(target.lines).rstrip() + "\n"
        target.path.parent.mkdir(parents=True, exist_ok=True)
        with target.path.open("w", encoding="utf-8", newline="\n") as handle:
            handle.write(rendered)
        written += 1

    obsolete = sorted(path for path in actual_paths if path not in expected_paths)
    for path in obsolete:
        path.unlink()
    link_failures: list[str] = []
    for target in targets:
        rendered = "\n".join(target.lines).rstrip() + "\n"
        link_failures.extend(validate_rendered_links(target.path, rendered))
    if link_failures:
        raise ValueError("INDEX mesh produced broken links:\n" + "\n".join(link_failures))
    print(f"Wrote index mesh: {written} files")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

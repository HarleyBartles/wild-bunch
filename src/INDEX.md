# src

Solution source projects for the Wild Bunch backend and web client.

## Subdirectories

- [WildBunch.Api/](WildBunch.Api/INDEX.md) - ASP.NET Core minimal-API HTTP boundary (game, travel, journal, store, investigation, dev endpoints).
- [WildBunch.Application/](WildBunch.Application/INDEX.md) - Application layer: commands, queries, handlers, mappers, projections, dev controls.
- [WildBunch.Domain/](WildBunch.Domain/INDEX.md) - Domain layer: GameSession aggregate root, cases, travel, inventory, economy, events, world.
- [WildBunch.GameContent/](WildBunch.GameContent/INDEX.md) - In-code game content: seeded new-game factory, world catalog, travel diary flavours.
- [WildBunch.Persistence/](WildBunch.Persistence/INDEX.md) - Persistence layer: EF DbContext, event store, session repositories, migrations, JSON serialization.
- [WildBunch.Web/](WildBunch.Web/INDEX.md) - React/Vite web play-surface client with dev overlay.

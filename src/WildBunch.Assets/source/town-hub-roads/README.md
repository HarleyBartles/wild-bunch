# Town Hub Roads Assets

This subtree is the source-custody home for the town-hub road tile track.

- Keep the canonical full-size road tile sources here.
- Use matching homes under `src/WildBunch.Assets/staging/town-hub-roads/` and
  `src/WildBunch.Assets/production/tiles/town-hub-roads/` for reviewable and shipped
  copies.
- This root is scaffolded before tile generation so later work has a stable
  custody home.

Do not use the web public folder as the working asset home.

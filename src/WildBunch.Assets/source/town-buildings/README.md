# Town Buildings Assets

This subtree is the source-custody home for the town-building family.

- The full-size custody assets live here under tier and family folders.
- Family-specific `AGENTS.md` guidance lives here alongside the source assets.
- The matching staging and shipping outputs live in `src/WildBunch.Assets/staging/`
  and `src/WildBunch.Assets/sprites/`.
- The current canonical building families are `general-store`, `sheriff-office`,
  `saloon`, and `telegraph-office`.
- The current prosperity tiers are `destitute`, `poor`, `prosperous`, and
  `boomtown`.
- Each family uses the same five-view turnaround contract across those tiers.

Do not use the web public folder as the working asset home.

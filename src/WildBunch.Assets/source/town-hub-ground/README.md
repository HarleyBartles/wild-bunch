# Town Hub Ground Assets

This subtree is the source-custody home for the town-hub ground tile track.

- Keep the canonical full-size ground and dirt tile sources here.
- Use matching homes under `src/WildBunch.Assets/staging/town-hub-ground/` and
  `src/WildBunch.Assets/sprites/town-hub-ground/` for reviewable and shipped
  copies.
- This root is scaffolded before tile generation so later work has a stable
  custody home.

Do not use the web public folder as the working asset home.

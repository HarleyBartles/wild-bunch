# src

Application source for the Wild Bunch web client.

## Subdirectories

- [api/](api/INDEX.md) - HTTP client, API types, and typed API client.
- [components/](components/INDEX.md) - React game surface components.
- [dev/](dev/INDEX.md) - Dev overlay surface, panel registry, and dev panels.
- [flow/](flow/INDEX.md) - Game flow routing and surface composition.
- [hooks/](hooks/INDEX.md) - React hooks for game session and phase state.
- [routes/](routes/INDEX.md) - Top-level route components.
- [shell/](shell/INDEX.md) - App shell, HUD, and router.
- [state/](state/INDEX.md) - Game session provider and state hook.
- [styles/](styles/INDEX.md) - Global SCSS styles, reset, and variables.
- [tests/](tests/INDEX.md) - Vitest test suites and test utilities.
- [ui/](ui/INDEX.md) - Shared UI helpers (formatters, seed codec).

## Key files

- [App.tsx](App.tsx) - Root application component.
- [main.tsx](main.tsx) - Application entrypoint.
- [styles.css](styles.css) - Global CSS entrypoint.
- [vite-env.d.ts](vite-env.d.ts) - Vite environment type declarations.

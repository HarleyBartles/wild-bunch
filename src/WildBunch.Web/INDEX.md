# WildBunch.Web

React/Vite web play-surface client with a dev overlay.

## Subdirectories

- [docs/](docs/INDEX.md) - Web-specific docs and unslop profiles.
- [src/](src/INDEX.md) - Application source (components, flow, hooks, routes, shell, state, dev, api, ui, tests, styles).

## Key files

- [package.json](package.json) - npm dependencies and scripts.
- [vite.config.ts](vite.config.ts) - Vite build and dev server configuration.
- [tsconfig.json](tsconfig.json) - TypeScript compiler configuration.
- [index.html](index.html) - HTML entrypoint.
- [AGENTS.md](AGENTS.md) - Scoped agent rules for web UI/play-surface work.
- [.gitignore](.gitignore) - Web-specific git ignore rules.
- [package-lock.json](package-lock.json) - npm lockfile.

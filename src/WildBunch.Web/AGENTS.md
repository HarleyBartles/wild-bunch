# Wild Bunch Web

Frontend standards for the Wild Bunch web app (`src/WildBunch.Web/`).

## Must Read When

- **Before implementing or reviewing any frontend work:** [`.agents/docs/frontend-standards.md`](../../.agents/docs/frontend-standards.md) — styling stack, play-surface UI, source truth, dev overlay, and routing conventions. This is the binding standards document for the frontend.
- **Before designing, implementing, or reviewing player-facing surfaces:** [`.agents/unslop/play-surface-ui.md`](.agents/unslop/play-surface-ui.md) — play-surface UI unslop profile.
- **Before touching dev overlay:** [`.agents/docs/dev-overlay-doctrine.md`](../../.agents/docs/dev-overlay-doctrine.md) and [`.agents/unslop/dev-overlay.md`](../../.agents/unslop/dev-overlay.md) — binding doctrine and unslop profile for dev overlay work.
- **Before writing or reviewing tests:** [`.agents/docs/validation-policy.md`](../../.agents/docs/validation-policy.md) — test kinds, validation commands, and test quality standards.
- **Before implementing or dispatching implementer subagents:** [`.agents/docs/implementing-guide.md`](../../.agents/docs/implementing-guide.md) — standards to read, skills to invoke, TDD discipline, pre-completion verification, PR/Linear/plan honesty, and subagent dispatch guidance.
- **Before planning multi-step frontend work:** [`.agents/docs/planning-guide.md`](../../.agents/docs/planning-guide.md) — standards to read, skills to invoke, plan structure requirements, and plan review checklist.
- **Before reviewing frontend work:** [`.agents/docs/code-review-guide.md`](../../.agents/docs/code-review-guide.md) — review methodology and lenses. Pay particular attention to the frontend review section and the player lens.

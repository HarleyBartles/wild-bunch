# WildBunch.Api

ASP.NET Core minimal-API HTTP boundary for the game.

## Subdirectories

- [Dev/](Dev/INDEX.md) - Dev-only endpoints and role guard.
- [Games/](Games/INDEX.md) - Game, travel, journal, store, investigation, wanted-poster, and projection endpoints.
- [Properties/](Properties/INDEX.md) - Launch settings.

## Key files

- [WildBunch.Api.csproj](WildBunch.Api.csproj) - Project file.
- [Program.cs](Program.cs) - Application entrypoint and middleware pipeline.
- [DependencyInjection.cs](DependencyInjection.cs) - Service registration extensions.
- [appsettings.json](appsettings.json) - Base app settings.
- [appsettings.Development.json](appsettings.Development.json) - Development app settings.
- [WildBunch.Api.http](WildBunch.Api.http) - HTTP request file for manual endpoint testing.
